# نظام ذكي لكشف التسلل والصيانة التنبؤية للشبكات (NIDS)

مشروع تخرج يبني خط معالجة كاملاً لتصنيف حركة الشبكة واكتشاف الهجمات على مجموعة
**CICIDS2017**، مع لوحة تحكم منشورة على الإنترنت.

**النتيجة النهائية: Macro-F1 = 0.9172** على مجموعة اختبار من 767,147 سجلاً،
بمعدل إنذارات كاذبة 0.07%.

## الفئات المستهدفة

`Benign` · `DoS_DDoS` · `PortScan` · `BruteForce` · `Botnet`

## النتائج

| الفئة | Precision | Recall | F1 | العدد |
| --- | --- | --- | --- | --- |
| Benign | 0.9958 | 0.9991 | 0.9975 | 701,523 |
| PortScan | 0.9996 | 0.9970 | 0.9983 | 27,949 |
| BruteForce | 0.9920 | 0.9928 | 0.9924 | 1,249 |
| DoS_DDoS | 0.9950 | 0.9203 | 0.9562 | 35,983 |
| Botnet | 0.4866 | 0.9413 | 0.6415 | 443 |

## المنهجية

- **تقسيم تسلسلي داخل كل يوم** (70/30 مع فاصل 500 صف) بدل التقسيم العشوائي،
  لأن سجلات CICIDS2017 المتجاورة شبه متطابقة فيتسرب بعضها بين التدريب والاختبار.
- **مجموعة تحقق منفصلة** (آخر 15% من جزء التدريب في كل يوم): كل الاختيارات اتُخذت
  عليها، ومجموعة الاختبار لم تُستعمل إلا للتقييم النهائي مرة واحدة.
- **ضبط المعاملات** بـ Optuna على مجموعة التحقق.
- **مقارنة عادلة** بين Random Forest وXGBoost بنفس عدد الأشجار ونفس معالجة عدم
  التوازن، مكررة على ثلاث بذور عشوائية.

## القيود

- البيانات من 2017، والنسخة المستعملة معدّلة من طرف ثالث.
- التقسيم تسلسلي لا زمني: الملف بلا عمود وقت.
- 89% من سجلات `DoS GoldenEye` وقعت في الاختبار و11% فقط في التدريب، ولذلك يفوت
  النموذج 31% منها. وأربعة أنواع فرعية لا وجود لها في الاختبار أصلاً.
- دقة `Botnet` 49% فقط: يكتشف 94% من الهجمات لكن نصف إنذاراته خاطئة.
- مجموعة بيانات واحدة، فالتعميم إلى شبكات أخرى غير مثبت.
- لا يوجد التقاط حي للحزم؛ اللوحة تحلل ملفات سجلات جاهزة.

## لوحة التحكم

أربعة تبويبات: فحص ملف سجلات، عيّنة تجريبية مع مقارنة بالتسميات الحقيقية،
صحة الشبكة عبر الزمن، ومحاكاة تدفق.

```bash
pip install -r requirements.txt
streamlit run app.py
```
